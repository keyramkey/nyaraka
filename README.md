# TRA Documents Exact Filler

TIN Certificate + Business License generator (Tanzania).

## Deploy on Vercel

1. Push this folder to a GitHub repository
2. Go to [vercel.com](https://vercel.com) → New Project → Import the GitHub repo
3. Deploy (Framework Preset: Other / no build needed)

The site will work immediately after deploy.

## Local

```bash
# Python
python -m http.server 8000

# or Node
npx serve .
```

Then open http://localhost:8000
